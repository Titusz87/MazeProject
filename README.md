Maze Solver using A* Algorithm

A console-based maze navigation application that implements the A* search algorithm to find optimal paths through grid-based mazes.

Overview

This project was inspired by an introductory AI subject assignment where the maze problem was introduced to students. It demonstrates a goal-based agent implementation that efficiently solves maze navigation challenges using the A* pathfinding algorithm.

Technologies Used
- Language: C#

Prerequisites
- .NET SDK installed on your machine
