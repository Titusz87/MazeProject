Maze Solver using A* Algorithm

A console-based maze navigation application that implements the A* search algorithm to find optimal paths through a grid-based maze.

Overview

This project was inspired by an introductory AI subject assignment where the maze problem was introduced to first-year students. It demonstrates a goal-based agent implementation that efficiently solves maze navigation challenges using the A* pathfinding algorithm.

Technologies Used
- Language: C#

Prerequisites
- .NET SDK installed on your machine

Running the Application
1. Clone the repository:
   $ git clone https://github.com/Titusz87/MazeProject.git
   
3. Build the project:
   $ dotnet build
   
5. Run the project:
   $ dotnet run
